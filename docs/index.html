Cortex

The agentic drive: cloud storage with a team of AI agents that read every file, organize it, catch contradictions, answer questions with citations, write new documents and run automations.

View source on GitHub Brainstorming & user flows

What the agents do

📂 Proactive organization

Every upload is titled, summarized, tagged and filed into smart folders that the agent names itself. You never create a folder.

🔎 Semantic retrieval

Ask in plain English. Answers cite the exact passage, prefer newer documents, and warn you when sources disagree.

⚠️ Conflict detection

The Sentinel cross-checks each new file. When the lease says $15,200/month but the plan budgeted $14,500, you find out immediately.

✍️ Cross-document synthesis

"Draft a requirements doc from the Aurora meetings" produces a living document that flags itself stale when new information arrives.

⚡ Automated workflows

Invoices go into an expense ledger and meetings into an action-item tracker, and you can write new rules in plain English.

🧭 Drive briefing

"Brief me" gives a status report of every project, open conflicts and live ledgers.

Run it locally

git clone https://github.com/ranet5-design/cortex-agentic-drive.git
cd cortex-agentic-drive
npm install
npm start            # open http://localhost:3000

Set ANTHROPIC_API_KEY to power the agents with Claude Opus 5.5. Without a key, the same agents run on offline heuristics. Cortex needs a Node.js server, so it runs locally; this page is its project site.
